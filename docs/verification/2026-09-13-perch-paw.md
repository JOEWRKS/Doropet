# Attached forepaw interaction — 2026-09-13

Approved: while attached to a window/taskbar edge, dragging a front paw deforms
only that paw without carrying the pet or losing the support. A short tap waves
only the selected paw three cycles. Ground body-region dragging remains disabled.

## Implementation

- PawHold/PawRelease are local interaction states, separate from whole-body carry.
  Input latches drag at4DIP, caps displacement radially at18DIP, and maps using
  captured facing. A tap up to350ms waves for600ms; a drag restores over220ms.
- Release uses the last displayed offset, not a fresh button-up pointer sample.
  Local interaction retains the platform owner and world position; real owner
  disappearance still cancels capture and starts the existing falling handoff.
- Raster deformation preserves the authored upper image byte-for-byte, anchors
  the shoulder, and leaves the opposite paw in front. Inward bend is limited to
  2.5 source pixels so the selected paw does not disappear behind its neighbour.
  No source PNG, ribbon, head/eye artwork or browser preview changed.
- Hit testing shares inverse deformation/sampling with rendering. A new press
  interrupts a released paw before runtime ownership flags are computed. Grabbing
  the same recovering paw retains its current stretch/angle without a shape snap.

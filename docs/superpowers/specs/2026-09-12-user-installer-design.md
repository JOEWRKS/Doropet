# 도로롱 사용자별 설치기 설계

상태: 검토 초안. 사용자는 제품 마감 진행을 승인했으며, 아래 설치·교체·제거
정책은 구현 전에 검토받는다. 계획과 진행 기록은 TASKS.md만 사용한다.

## 범위

검증된 제품 셸 위에 Windows x64 설치·재설치·업그레이드·제거 패키지를 만든다.
캐릭터 그림, 모션, 입력, 물리, 트레이 명령은 바꾸지 않는다. 설치 안전성을 위한
제품 실행 상태 확인이 필요하면 제품 관리 계층에만 한정한다.

현재 입력 후보는 source074b643의 candidate-20260912-1751이다. 설치기 빌드는
입력의 버전과 해시를 확인하며, 검증 없이 앱을 다시 빌드하거나 다른 DLL로
바꾸지 않는다. 관리 계층 수정이 필요하면 전체 회귀·새 후보 검증을 먼저 한다.

## 방식 선택

추천은 Inno Setup 기반 일반 EXE 설치기다. 사용자별 설치와 기존 비패키지 WPF
실행 구조를 유지한다. MSIX는 패키지 식별자와 서명을 포함한 다른 배포 경계가
생기므로 이번 단계에서 동시에 도입하지 않는다. 자체 제작 설치 엔진은 파일
교체·등록·제거 책임을 새로 구현해야 하므로 선택하지 않는다.

빌드 도구는 공식 배포처에서 버전·출처를 확인해 고정한다. 현재 확인한 PATH와
표준 설치 경로에는 Inno Setup 컴파일러가 없다. 도구 확보 시 시스템 전체 등록,
관리자 설치, 라이선스 구매를 묵시적으로 수행하지 않는다. 공개 배포의 서명과
권리 검토는 별도 출시 조건이다.

## 설치 경험과 파일 소유권

- 배포물: Dororong-Setup-0.1.0-win-x64.exe 형태의 버전 표시 설치 파일.
- 기본 경로: %LocalAppData%/Programs/JOEWRKS/Dororong. 관리자 권한을
  요청하지 않으며 시스템 폴더와 HKLM에 설치하지 않는다.
- 시작 메뉴에 도로롱 바로가기를 만들고 Windows 앱 제거 목록에 제품명,
  버전, 게시자, 아이콘과 제거 명령을 등록한다. 버전이 바뀌어도 동일 제품 ID다.
- 바탕화면 바로가기는 기본 해제된 선택 항목이다. 자동 시작·서비스·업데이터는
  등록하지 않는다. 설치 완료 후 실행은 사용자가 선택하며 무인 설치는 자동 실행하지 않는다.
- 런타임을 포함한 검증된 전체 payload를 설치한다. 컴퓨터의 공유 .NET 런타임을
  설치·업데이트하지 않는다. 내부 Dororong.App.dll 및 리소스 이름은 유지한다.
- 최초 버전은 전용 기본 설치 위치를 사용한다. 다운로드 폴더의 개발판이나
  기존 portable 폴더를 찾아 지우거나 자동으로 가져오지 않는다.

## 재설치와 업그레이드

같은 버전은 재설치/복구를 허용하고, 높은 버전은 같은 제품으로 갱신한다.
낮은 버전의 덮어쓰기는 차단하고 별도 제거 후 설치가 필요함을 안내한다.
버전 비교는 숫자 버전으로 하며 문자열 사전순 비교를 사용하지 않는다.

설치·제거를 동시에 진행하지 못하도록 잠근다. 설치 대상 앱이 실행 중이면
사용자에게 종료를 요청한다. 프로세스 이름만 보고 다른 실행본을 강제 종료하지
않고, 무인 실행은 필요한 종료 조건이 충족되지 않으면 실패 코드로 끝낸다.
파일이 사용 중일 때 강제 덮어쓰기나 재부팅 후 교체 예약으로 우회하지 않는다.
다른 로그인 세션의 사용 중 파일도 검증 대상이며, 현재 세션 mutex만으로
모든 세션이 안전하다고 간주하지 않는다.

입력 누락·해시 불일치·버전 거절·취소 등 사전 실패는 기존 설치를 변경하지 않는다.
설치 도중 파일 잠금·용량 부족 등 실패는 성공으로 보고하지 않으며 기존 제품을
복구하거나 재설치가 필요한 상태를 명시적으로 알린다. 검증 전에는 전원 차단까지
포함한 완전한 원자적 교체나 무조건적 자동 복구를 보장한다고 표현하지 않는다.
구버전 파일 정리는 설치기가 소유한 파일 목록으로 제한한다.

## 제거와 데이터 보존

제거기는 자신이 설치한 파일, 바로가기, 제품 등록만 제거한다. 설치 경로 전체를
와일드카드로 재귀 삭제하지 않는다. 사용자가 추가한 파일은 남긴다.
%LocalAppData%/JOEWRKS/Dororong/logs는 별도 사용자 데이터로 취급해 보존한다.
사용자 프로필·Downloads·프로젝트·다른 후보·공유 런타임을 삭제하지 않는다.
개인 데이터 전체 삭제 옵션은 이번 범위에 추가하지 않는다.

## 검증과 전달 경계

1. 기존 패키지 검증으로 payload의 제품 ID·해시·자체 포함 런타임을 확인한다.
2. 설치기 생성·입력 거절·고정 버전·파일 목록과 메타데이터를 자동 검사한다.
3. 격리된 시험 환경에서 최초 설치, 동일 버전 재설치, 상위 버전 업그레이드,
   하위 버전 거절, 실행 중 작업 거절, 취소·실패, 정상 제거를 확인한다.
4. 로그와 추가 파일 보존, 시작 메뉴/제거 등록, 잔존 제품 프로세스·아이콘을 확인한다.
5. 시험용 상위 버전은 시험용으로 명확히 구분하고 실제 제품 버전을 몰래 올리지 않는다.

사용자 Windows에 실제 설치하거나 레지스트리/바로가기를 바꾸는 시험은 별도
인계에서 알리고 진행한다. 격리 시험 환경이 없으면 해당 검증은 미완료로 남기며
정적 검사만으로 설치/제거가 검증됐다고 하지 않는다. 첫 산출물은 새 artifact
디렉터리의 로컬 설치 후보와 검증 기록이다. 서명, 원격 푸시, 공개 업로드,
자동 업데이트 서버, 유료 구매는 이번 승인의 범위가 아니다.
